# Competition Requirements

The official brief requires:

1. Two ordered lists: Top 10 batters and Top 10 bowlers under pressure.
2. A methodology report explaining the pressure definition, metrics, baselines, fair-comparison logic, sample-size handling, reliability, limitations, and evidence.
3. Rank 1 as the highest-rated player and no repeated player within a list.
4. Reproducible analysis based only on the supplied data.

The brief allows teams to define pressure and use any defensible indicators. It requires IPL and T20I context to be considered, but does not prescribe a specific formula. Submission dropdown selections must match the report; the brief does not require an auction-recommendation section in the methodology report, but this project adds it only as analytical context.
